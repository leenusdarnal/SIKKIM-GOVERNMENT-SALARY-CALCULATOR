# Sikkim Government Salary Calculator

A web-based salary calculator for Sikkim Government employees. Calculate estimated monthly gross and net pay using the current pay matrix, DA, HRA, and statutory deductions.

## Features

- **Pay Matrix Reference**: View all 16 pay levels with corresponding basic pay, DA, HRA, and gross salary
- **Salary Calculation**: Input pay band and allowance rates to estimate take-home pay
- **Deduction Breakdown**: See detailed earnings and deductions (PF, Professional Tax, etc.)
- **Dark Mode**: Toggle between light and dark themes
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Print-Friendly**: Export salary summaries as PDF

## How to Use

1. Open `index.html` in your web browser
2. Select your pay level and band
3. Set Dearness Allowance (DA) and House Rent Allowance (HRA) rates
4. Click "Calculate Salary" to view gross, deductions, and net pay
5. Review the detailed breakdown or print the report

## Pay Matrix Levels

The calculator supports all 16 government pay levels from ₹18,000 to ₹68,900 basic pay.

## Disclaimer

This calculator provides **estimated values for reference only** and does not replace official government payroll systems. Use this tool for budgeting and planning purposes. For official salary details, consult your department's HR or payroll office.
